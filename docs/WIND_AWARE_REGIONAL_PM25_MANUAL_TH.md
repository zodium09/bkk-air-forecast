# คู่มือแบบจำลอง PM2.5 ภูมิภาคและการประมาณเชิงพื้นที่ตามทิศลม

## 1. วัตถุประสงค์

ระบบนี้ประมาณ PM2.5 สำหรับกรุงเทพมหานครและปริมณฑลโดยพิจารณามวลอากาศจากพื้นที่รอบข้าง ไม่คำนวณแยกจังหวัดแล้วนำผลมาต่อกัน และไม่ตีความ IDW ธรรมดาว่าเป็นการระบุแหล่งกำเนิดมลพิษ

ผลลัพธ์มีวัตถุประสงค์เพื่อการเฝ้าระวังเชิงพื้นที่ ไม่ใช่การยืนยันสาเหตุทางกฎหมาย การควบคุมแหล่งกำเนิด หรือคำแนะนำสุขภาพอย่างเป็นทางการ

## 2. โดเมนวิเคราะห์

โดเมนคงที่ครอบคลุมประมาณละติจูด 12.65–15.25 องศาเหนือ และลองจิจูด 99.15–101.85 องศาตะวันออก หรือประมาณ 100–200 กิโลเมตรรอบกรุงเทพฯ ครอบคลุม:

- กรุงเทพฯ และห้าจังหวัดปริมณฑล
- พระนครศรีอยุธยา อ่างทอง สุพรรณบุรี
- ราชบุรี สมุทรสงคราม และเพชรบุรีตอนบน
- ลพบุรีตอนล่าง สระบุรี และนครนายก
- ฉะเชิงเทรา ปราจีนบุรี และชลบุรีตอนบน
- อ่าวไทยตอนบน ซึ่งมีผลต่อลมทะเล

ขอบเขตจังหวัดใช้สำหรับการแสดงผลและสรุปผลเท่านั้น ไม่ใช้เป็นกำแพงในการคำนวณการเคลื่อนที่ของอากาศ

## 3. แหล่งข้อมูล

1. **CAMS Global PM2.5** ใช้เป็น regional background ผ่าน Open-Meteo Air Quality API ค่ามีความละเอียดพื้นฐานประมาณ 0.4 องศาหรือราว 45 กิโลเมตร และเป็นค่าฝุ่นใกล้ผิวพื้น หน่วย µg/m³  
   เอกสาร: https://open-meteo.com/en/docs/air-quality-api
2. **AirBKK** ใช้ค่าตรวจวัดในกรุงเทพฯ
3. **Air4Thai ของกรมควบคุมมลพิษ** ใช้สถานีที่อยู่ภายในโดเมนภูมิภาค
4. **ข้อมูลลมจาก Open-Meteo Weather Forecast** ใช้ความเร็วลม 10 เมตรและทิศที่ลมพัดมา  
   เอกสาร: https://open-meteo.com/en/docs
5. **ขอบเขตการปกครอง BMA/DMR** ใช้ clip การแสดงผล

CAMS เป็นแบบจำลององค์ประกอบบรรยากาศระดับโลก ไม่ใช่สถานีตรวจวัด รายละเอียดระบบ CAMS:  
https://confluence.ecmwf.int/pages/viewpage.action?pageId=673323626

## 4. ขั้นตอนคำนวณ

### 4.1 Regional background

ระบบสร้างกริด CAMS 7×7 รวม 49 จุดทั่วโดเมน ความห่างใกล้เคียงความละเอียดจริงของ CAMS Global เพื่อหลีกเลี่ยงการสร้างจุดจำนวนมากเกินข้อมูลต้นทาง

สำหรับตำแหน่งเป้าหมาย x และเวลา t:

```text
B(x,t) = IDW ของ CAMS รอบตำแหน่ง x
```

ใช้จุด CAMS ใกล้สุดไม่เกิน 8 จุด ภายใน 120 กิโลเมตร

### 4.2 Station residual

ทุกสถานีที่ผ่านการตรวจคุณภาพคำนวณค่าคลาดเคลื่อน:

```text
rᵢ = Observationᵢ − CAMSᵢ
```

residual ถูกจำกัดช่วง −60 ถึง +60 µg/m³ เพื่อป้องกันสถานีผิดปกติจุดเดียวครอบงำพื้นผิว

การตรวจคุณภาพประกอบด้วย:

- พิกัดและค่าอยู่ในช่วงสมเหตุผล
- ไม่ใช้ข้อมูลอนาคตหรือเก่าเกินเกณฑ์
- ตัดสถานีซ้ำ
- ตรวจ outlier โดยคง hotspot ที่มีสถานีใกล้เคียงยืนยัน

### 4.3 น้ำหนักตามทิศลม

ทิศลมอุตุนิยมวิทยาหมายถึง “ทิศที่ลมพัดมา” ระบบสร้างแกนจากตำแหน่งเป้าหมายไปยังด้านเหนือลม แล้วแยกระยะของสถานีเป็น:

- ระยะตามแนวลม (along-wind)
- ระยะตั้งฉากกับแนวลม (cross-wind)
- สถานีด้านใต้ลม (downwind)

ด้านเหนือลมถูกยืดแกนให้มีอิทธิพลไกลกว่า ด้านข้างถูกลดน้ำหนัก และด้านใต้ลมได้รับตัวคูณ 0.15

```text
wᵢ = directional_factor × temporal_decay / effective_distance²
```

เมื่อความเร็วลมน้อยกว่า 3.6 กม./ชม. หรือไม่มีทิศลม ระบบใช้ระยะสมมาตร 50 กม. เพราะไม่ควรอ้างทิศทางในภาวะลมสงบ

เมื่อมีลม ระยะอิทธิพลคำนวณจากความเร็วลมคูณหน้าต่าง 8 ชั่วโมง และจำกัดไว้ที่ 60–180 กม.

### 4.4 การลดอิทธิพลตามเวลา

residual จากสถานีเป็นข้อมูลปัจจุบัน จึงลดน้ำหนักเมื่อข้อมูลเก่าหรือระยะพยากรณ์ยาวขึ้น:

```text
temporal_decay = exp(−(observation_age_hours + lead_hours) / 48)
```

ดังนั้นพยากรณ์ระยะไกลจะค่อย ๆ กลับไปพึ่ง CAMS background มากขึ้น แทนการลากค่าปัจจุบันไปตลอดเจ็ดวัน

### 4.5 ค่าประมาณสุดท้าย

```text
PM2.5(x,t) = clamp(B(x,t) + weighted_residual(x,t), 0, 500)
```

หากไม่มีสถานีที่อยู่ในพื้นที่อิทธิพล ระบบใช้ CAMS background โดยไม่สร้าง correction เทียม

ระบบคำนวณ 54 จุดเป้าหมายที่ครอบคลุมกรุงเทพฯ และปริมณฑล จากนั้นจึงสร้างผิวต่อเนื่องและ clip ด้วยขอบเขตทางการ การ interpolation ขั้นสุดท้ายมีหน้าที่แสดงภาพเท่านั้น ไม่ถูกนำกลับไปใช้เป็นหลักฐานวิเคราะห์อิทธิพล

## 5. เหตุผลทางอุตุนิยมวิทยา

ประเทศไทยได้รับอิทธิพลจากมรสุมตะวันตกเฉียงใต้และตะวันออกเฉียงเหนือ แต่วันเริ่มต้น สิ้นสุด และทิศลมรายวันเปลี่ยนได้ จึงใช้ข้อมูลลมของวันพยากรณ์แทนการเลือกจังหวัดด้วยฤดูกาลแบบตายตัว  
กรมอุตุนิยมวิทยา: https://tmd.go.th/info/%E0%B8%A5%E0%B8%A1%E0%B8%A1%E0%B8%A3%E0%B8%AA%E0%B8%B8%E0%B8%A1

งานศึกษา Greater Bangkok พบว่าการเคลื่อนย้ายมวลอากาศจากทิศตะวันออกและตะวันออกเฉียงเหนือ รวมถึงลมบก–ลมทะเล สามารถสัมพันธ์กับเหตุการณ์หมอกควันได้:

- https://www.mdpi.com/1660-4601/17/24/9499
- https://www.mdpi.com/1660-4601/20/4/3482

หลักฐานดังกล่าวสนับสนุนการใช้ทิศลมเป็นตัวถ่วงน้ำหนัก แต่ไม่เพียงพอให้สรุปว่าสถานีหรือจังหวัดเหนือลมเป็นแหล่งกำเนิด

## 6. การตีความหน้าจอ

- สีคือค่าประมาณ PM2.5 ไม่ใช่ค่าตรวจวัดทุกพิกเซล
- “พื้นที่เหนือลมมีอิทธิพล” หมายถึงมีน้ำหนักเชิงแบบจำลองสูงขึ้น ไม่ได้แปลว่าเป็นต้นเหตุ
- ช่องว่างหรือโหมด degraded หมายถึงแหล่งข้อมูลประกอบไม่ครบ
- คะแนนความน่าเชื่อถือเป็น heuristic ไม่ใช่ probability
- ควรอ้างประกาศจากหน่วยงานทางการเมื่อตัดสินใจด้านสุขภาพหรือมาตรการ

## 7. การตรวจสอบความแม่นยำที่ต้องทำต่อ

ก่อนใช้เพื่อการตัดสินใจเชิงนโยบาย ต้องทำ historical backtest อย่างน้อยหนึ่งฤดูฝุ่น โดย:

1. ทำ leave-one-station-out รายชั่วโมงหรือรายวัน
2. เปรียบเทียบ CAMS ดิบ, IDW สมมาตร และโมเดล wind-aware
3. รายงาน MAE, RMSE, bias และ spatial coverage
4. แยกผลตามทิศลม ความเร็วลม ฤดู และช่วงลมสงบ
5. ตรวจเหตุการณ์ลมทะเลและ cold surge แยกจากวันทั่วไป
6. ปรับพารามิเตอร์ด้วยชุดฝึก และรายงานผลด้วยชุดทดสอบคนละช่วงเวลา

ค่าพารามิเตอร์ในรุ่นปัจจุบันเป็น engineering defaults ที่มีเหตุผลทางกายภาพ แต่ยังไม่ถือว่าได้รับการสอบเทียบเชิงสถิติ

## 8. ข้อจำกัด

- CAMS Global มีความละเอียดหยาบกว่าระดับเขตและถนน
- ลม 10 เมตรที่จุดอ้างอิงเดียวไม่แทนโครงสร้างลมสามมิติทั้งหมด
- ระบบยังไม่ใช้ back trajectory เช่น HYSPLIT
- ยังไม่ใช้ความสูงชั้นผสมอากาศ การผกผันอุณหภูมิ หรือบัญชีการปล่อยมลพิษโดยตรง
- ค่าจากสถานีหลายเครือข่ายอาจมีความต่างด้านเครื่องมือและการสอบเทียบ
- โมเดลนี้ประมาณการกระจายเชิงพื้นที่ ไม่ใช่ source-apportionment model

## 9. การควบคุมเวอร์ชันวิธีคำนวณ

เมื่อเปลี่ยนโดเมน พารามิเตอร์ลม ระยะอิทธิพล แหล่งข้อมูล หรือเกณฑ์ QC ต้อง:

1. เพิ่ม unit test ของพฤติกรรมเชิงทิศทาง
2. รัน failure tests ของทุก upstream
3. อัปเดตคู่มือนี้
4. ระบุการเปลี่ยนแปลงใน release/commit
5. ห้ามเรียกผลว่า “แม่นยำขึ้น” จนกว่าจะผ่าน backtest กับข้อมูลที่ไม่ได้ใช้ปรับพารามิเตอร์
