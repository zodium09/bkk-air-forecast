# น้ำขึ้นน้ำลงกับฝน

หน้าระดับน้ำและบทระดับน้ำในภาพรวมแยกการวางแผนจากน้ำทำนายออกจากเหตุการณ์ตรวจวัดจริง ผู้ใช้เลือก 4 สถานีและวันที่ใน 7 วันข้างหน้า กราฟน้ำทำนายกับฝนอยู่บนแกนเวลาเดียวกัน แต่มีแกนตั้งคนละหน่วย เลือกต้นชั่วโมงด้วยการแตะหรือปุ่มลูกศร และอ่านตัวเลขเป็นตารางได้ สรุป 48 ชั่วโมงถัดไปคงช่วงปัจจุบันเมื่อเปลี่ยนวันที่ของกราฟ

## ข้อมูลน้ำทำนาย

- [กรมอุทกศาสตร์ กองทัพเรือ: มาตราน้ำ พ.ศ.2569](https://hydro.navy.mi.th/waterlaveltable) ใช้ไฟล์ **MSL** ของป้อมพระจุลจอมเกล้า ท่าเรือกรุงเทพ กองบัญชาการกองทัพเรือ และปากน้ำท่าจีน
- เป็นทำนายรายต้นชั่วโมง หน่วยเมตรเหนือระดับทะเลปานกลาง ความละเอียด 0.1 ม. ค่าติดลบคงไว้
- เก็บตัวเลขครบ 8,760 ชั่วโมงต่อสถานี พร้อม URL และ SHA-256 ของ PDF ไว้ที่ `app/data/tide-predictions-2026.json` ข้อมูลรายปีโหลดเฉพาะฝั่งเซิร์ฟเวอร์ ไม่ส่งทั้งปีเข้าเบราว์เซอร์
- ตัวนำเข้าที่ `scripts/import-tide-tables.py` ตรวจ 12 เดือน ปี datum ลำดับวัน จำนวน 24 ชั่วโมงต่อวัน และพิกัดสถานี ก่อนเขียนผล ต้องดาวน์โหลด PDF จาก URL ใน `app/data/tide-stations.json` เป็น CODE.pdf แล้วรัน `python -X utf8 scripts/import-tide-tables.py --pdf-dir PATH` (ต้องมี pdfplumber)
- อ้างอิงจุดสูงสุด/ต่ำสุดจาก 24 ค่าต้นชั่วโมงของวันนั้น แสดงเวลาทุกจุดที่เท่ากัน ไม่อ้างเป็นนาทีที่น้ำขึ้น/ลงเต็มที่จริง และไม่เติมเส้นสมมติเมื่อค่าขาด
- หมดปีแล้วไม่ใช้ปีเดิมแทนปีใหม่ ต้องตรวจแหล่งใหม่และเปลี่ยนชุดข้อมูล/API ก่อนเปิดการวิเคราะห์ปีถัดไป

## ฝนและการเทียบเวลา

API `/api/tide-outlook` รับเฉพาะสถานีที่กำหนดและวันปัจจุบันเวลาไทย ไม่รับ URL หรือพิกัดอิสระ ขอฝนจาก Open-Meteo Best Match ณ พิกัดสาธารณะของสถานี ไม่ส่ง GPS ผู้ใช้ ฝนเป็นพยากรณ์จากกริดรอบสถานี ไม่ใช่ฝน ณ บ้านผู้ใช้

[นิยาม Open-Meteo](https://open-meteo.com/en/docs): precipitation ณ 11:00 เป็นยอดชั่วโมง 10:00–11:00 น้ำทำนาย ณ 11:00 เป็นค่าต้นชั่วโมง ฟังก์ชันแปลงเวลาเลื่อนปลายช่วงให้ตรงกัน รวมทั้งชั่วโมงข้ามเที่ยงคืน ต้องมีหน่วย mm และ UTC offset +7 ที่ถูกต้อง ค่าลบ ผิดหน่วย เวลาซ้ำ หรือค่าขาดไม่กลายเป็นศูนย์

คำว่า **ฝนซ้อนน้ำสูง** เป็นตัวคัดช่วงช่วยเฝ้าดูของแอป: ฝน ≥10 มม. ในกรอบ 3 ชั่วโมง และมีน้ำทำนายใกล้ค่าสูงสุดรายชั่วโมงของวันที่เลือกไม่เกิน 0.2 ม. ใช้ฝนครบ 3 ค่า น้ำครบ 4 จุดครอบช่วง และน้ำครบวันสำหรับหาสูงสุด ไม่ใช่เกณฑ์ฝนรายวันของกรมอุตุฯ เกณฑ์ระดับตลิ่ง โอกาสท่วม หรือประกาศเตือนภัย ช่วงสามชั่วโมงอาจมีฝนก่อนหรือหลังน้ำสูงภายในช่วงเดียวกัน ไม่ยืนยันการเกิดตรงนาที

น้ำสูงอย่างเดียว ฝนเด่นอย่างเดียว ยังไม่เข้าเกณฑ์ และข้อมูลไม่พอ แสดงแยกกัน การไม่พบช่วงซ้อนไม่แปลว่าปลอดน้ำท่วม ช่วงที่ขาดข้อมูลแสดงจำนวนในสรุปเสมอ ยังเก็บน้ำทำนายได้เมื่อฝน upstream ไม่พร้อม พยากรณ์ฝนที่รับมาเกิน 60 นาทีไม่ใช้วิเคราะห์ในหน้าจอ API cache 30 นาทีเมื่อครบ และ 10 นาทีเมื่อขาด พร้อมรวมคำขอซ้ำ

## พื้นที่และหลักฐานตรวจวัด

เลือกสถานีอัตโนมัติที่ใกล้จุดอ้างอิงที่สุดภายใน 25 กม. ระยะนี้เป็นขอบเขตเลือกสถานีของแอป ไม่ใช่เส้นขอบอิทธิพลน้ำหนุน พื้นที่นอกระยะดูปากแม่น้ำเป็นบริบท พร้อมข้อความว่าไม่สรุปช่วงเสี่ยงเฉพาะพื้นที่นั้น เลือกสถานีเองได้ ไม่ใช้ข้อมูลปากเจ้าพระยาอ้างเป็นน้ำหนุนทั้งลุ่มน้ำ

หลักฐานจริงรอบสถานีน้ำทำนาย 8 กม. ใช้เกณฑ์น้ำ ThaiWater ที่มีค่าภายใน 60 นาที และสถานะถนนจาก กทม. ภายใน 30 นาที แยกน้ำน้อยออกจากน้ำมาก มีตัวหารของจุดที่ใช้ได้และแสดงเวลาเมื่อพบเหตุ ค่าที่ไม่ทราบเกณฑ์ ล่าช้า ขัดข้อง อยู่ไกลหรือเวลาอนาคตไม่ถูกนับเป็นปกติ หลักฐานคงเวลาปัจจุบันแม้เลือกวันทำนายอื่น ไม่มีการลบระดับต่างสถานีหรืออ้าง datum ต่างกันเป็นส่วนต่างน้ำ

[กรมชลประทาน](https://www.rid.go.th/th/rid_news/28895) ระบุว่าฝน น้ำจากพื้นที่ตอนบนและน้ำทะเลหนุนมีผลต่อระดับน้ำและประสิทธิภาพการระบาย การเทียบกราฟนี้ช่วยอธิบายการซ้อนปัจจัยตามเวลา ยังไม่มีแบบจำลองน้ำหลาก ประตูน้ำ เครื่องสูบน้ำ ระดับถนนหรือ storm surge จึงไม่อ้างพยากรณ์ความลึกน้ำท่วม ผลทางสถิติ หรือความสัมพันธ์เชิงเหตุเป็นตัวเลข
