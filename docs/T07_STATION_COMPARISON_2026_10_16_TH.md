# T07 · เทียบสถานีระดับน้ำ 2–4 จุด

สถานะ 16 ต.ค. 2569: implement ใน working tree แล้ว ยังไม่ผ่าน Gate D หรือ deploy

## พฤติกรรมที่ส่งต่อ

- ผู้ใช้เปิด `/explore`, เลือกสถานีจากรายการหรือจุดแผนที่ แล้วกด **เพิ่มในการเทียบ** ที่รายละเอียดสถานี เลือกได้สูงสุด 4 จุด ข้ามลุ่มน้ำได้; ปุ่มจะปิดเมื่อเต็ม แต่สถานีที่เลือกแล้วยังเอาออกได้
- URL `compare=sourceId1,sourceId2` เก็บ public source ID ที่ผ่านการตรวจรูปแบบ ลบค่าซ้ำและจำกัด 4 รหัส เปิดลิงก์อีกแท็บแล้วคืนชุดเทียบได้ การเปลี่ยนพื้นที่ยังคงชุดเทียบจากลุ่มอื่น โดยแสดงชื่อพื้นที่แต่ละสถานีไว้
- 24/72 ชั่วโมงใช้ข้อมูลจาก `/api/water-history` เท่านั้น เคอร์เซอร์ร่วมเดินบนเวลาที่มีค่าตรวจวัดจริงของอย่างน้อยหนึ่งสถานี ไม่สร้างค่ากลางหรือเวลาเดินทางน้ำ หากสถานีไม่มีค่าภายใน 60 นาทีก่อนเคอร์เซอร์จะแสดงว่าไม่มีค่าใกล้เวลานั้น
- กราฟใช้แกนนอนเวลาเดียวกัน แต่แต่ละสถานีมีแกนตั้งและ datum ของตัวเอง จุดเดี่ยวแสดงเป็นจุดพร้อมข้อความว่ายังบอกแนวโน้มไม่ได้ ช่วงห่างเกิน 1 ชั่วโมงตัดเส้น ตารางขยายแสดงค่าตรวจวัดจริงทั้งหมดในช่วง
- แสดงประวัติว่าง, คลังไม่พร้อม, และสถานีที่ feed ล่าสุดหาย เป็นคนละสถานะ ไม่ให้ค่าขาดกลายเป็น 0 หรือคำว่าปลอดภัย คำอธิบายเตือนว่าไม่ใช้ความสูง รทก. ข้ามสถานีจัดอันดับความเสี่ยง
