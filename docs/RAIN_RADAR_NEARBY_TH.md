# เรดาร์และแนวโน้มฝนใกล้พื้นที่

เพิ่มในหน้าภาพรวมส่วนฝนและน้ำ และหน้า `/rain` เมื่อ 2 ตุลาคม 2026 โดยคงการพยากรณ์และการเลือกเวลาเดิมไว้ เรดาร์กับผลวิเคราะห์ใกล้เคียงตามเวลาปัจจุบันเสมอ แม้ผู้ใช้เลื่อนวันของพยากรณ์

## ข้อมูลจริงจากต้นทาง

- ภาพตรวจพบและ Nowcast: [TMD RadarGIS](https://radargis.tmd.go.th/) ผ่าน `/api/overlays` ใช้ผลิตภัณฑ์ `rainrate` หน่วย `mm/h` และขอบเขตภาพที่ต้นทางระบุ
- ผลวิเคราะห์รอบตำแหน่ง: `/api/location_nowcast_alert?lat=…&lon=…&radius_km=8` ของต้นทาง ส่งผ่าน `/api/rain-nearby` ในแอป ใช้ `found`, `message`, `place` ที่ต้นทางส่งกลับโดยไม่คำนวณความเร็วกลุ่มฝนหรือสร้างเวลาฝนมาถึงเอง
- จุดพยากรณ์ใกล้เคียง: ชุด `/api/rain-places` เดิม ใช้ค่ารายชั่วโมงตามพิกัดจาก Open-Meteo แสดงสูงสุด 4 จุดในระยะ 8 กม. ไม่มี IDW และไม่แปลงโอกาสฝนเป็นปริมาณฝน

ผลวิเคราะห์ตำแหน่งของต้นทางไม่ส่งเวลาของตัวเอง แอปตรวจความใหม่ร่วมกับภาพฐานของแค็ตตาล็อก แต่ไม่ได้อ้างว่าทั้งสอง API เป็น snapshot เดียวกัน เมื่อภาพฐานเกิน 30 นาที หรือไม่มี Nowcast ที่ยังไม่หมดเวลา จะไม่สรุปว่าพบฝนหรือปลอดฝน ภาพตรวจจริงเกิน 90 นาทีไม่แสดง และภาพตรวจจริงที่อยู่ในอนาคตเกินค่าคลาดเคลื่อน 5 นาทีไม่ถูกใช้เป็นฐาน

อัตราฝนจากเรดาร์เป็นค่าประมาณ หน่วย มม./ชม. กราฟใกล้เคียงเป็นยอดสะสมของแต่ละช่วงชั่วโมง หน่วย มม. แสดงแยกกัน รวมชั่วโมงปัจจุบันเต็มช่วงและอีก 2 ชั่วโมงถัดไป ไม่ใช่ยอดตั้งแต่นาทีที่เปิดหน้า ยอดรวมต้องมีครบ 3 ชั่วโมง โอกาสฝนเป็นค่าสูงสุดรายชั่วโมง ไม่ใช่โอกาสเกิดฝนรวมทั้งช่วง

## การใช้งาน

เลือกพื้นที่ที่ส่วน “พื้นที่ของฉัน” หรือคลิกแผนที่เรดาร์ ในหน้าภาพรวมจะเลือกจุดอ้างอิงสาธารณะที่ใกล้จุดกดที่สุดและแจ้งระยะ ส่วนหน้าฝนใช้จุดที่เลือกบนแผนที่โดยตรง ไม่มีการขอตำแหน่งอุปกรณ์อัตโนมัติ

เปิด “ติดตามฝนพื้นที่นี้” เพื่อรับแถบแจ้งเตือนในแอปเมื่อผลวิเคราะห์ต้นทางพบฝนขณะเปิดหน้า ปิดแจ้งเตือนรอบหนึ่งแล้วข้อความเดิมจะไม่เด้งซ้ำ แม้โหลดข้อมูลใหม่ ผลที่เปลี่ยนหรือการเปิดติดตามใหม่แสดงได้อีก ไม่มี push เมื่อปิดแอป อีเมล หรือข้อความภายนอก

โหลดข้อมูลใหม่ทุก 5 นาทีขณะหน้ามองเห็น และตรวจความใหม่ตามนาฬิกาทุกนาที ผลตำแหน่งใช้ `no-store` ไม่มีการบันทึกพิกัดในฐานข้อมูลหรือพื้นที่เก็บข้อมูลของเบราว์เซอร์ พิกัดจุดที่เลือกถูกส่งไป TMD RadarGIS เพื่อวิเคราะห์บริเวณนั้น

เล่นภาพตามเวลาจริงของต้นทาง เลื่อนทีละภาพ ปรับความทึบ และเปลี่ยนตรวจจริง/Nowcast ได้ การเล่นรอภาพโหลดสำเร็จก่อนเลื่อนไปเฟรมถัดไป หยุดเมื่อซ่อนหน้า และปิดการเล่นอัตโนมัติตาม `prefers-reduced-motion` รูปเมืองบนหน้าแรกเป็นภาพประกอบที่สร้างด้วย Imagegen ไม่ใช่ข้อมูลสภาพอากาศ

## ตรวจสอบ

ชุดทดสอบครอบคลุมผลพบ/ไม่พบฝน ข้อมูลเก่า/อนาคต Nowcast ขาด ต้นทางขัดข้อง ค่าศูนย์จริง ช่องข้อมูลที่หาย การข้ามเที่ยงคืนตามเวลาไทย ขอบเขตพิกัดและการไม่เก็บ cache ผลตำแหน่ง

ตรวจเบราว์เซอร์ด้วยข้อมูลจริงที่สุขุมวิท: เลือกพื้นที่แล้วผลจากต้นทางและจุดพยากรณ์ใกล้เคียงสัมพันธ์กัน ภาพ Nowcast เล่นต่อเนื่อง ปุ่มความทึบทำงาน พร้อมตรวจหน้าจอ 390 พิกเซล การแจ้งเตือนและการไม่เด้งซ้ำตรวจด้วยชุดข้อมูลทดสอบบนตัวกลางเฉพาะในเครื่อง ซึ่งแยกจากแอปจริงและระบุว่าเป็นข้อมูลทดสอบ
