# แผนที่สรุปพื้นที่และระดับติดตาม

หน้าภาพรวมเพิ่มแผนที่เรื่องสำคัญปัจจุบัน 5 เรื่อง: น้ำบนถนน คลอง/แม่น้ำ ฝุ่นตรวจวัด ฝนใกล้พื้นที่ และความร้อนของช่วงปัจจุบัน กด “ดูพื้นที่บนแผนที่” ในรายการเหตุการณ์เพื่อกรองเฉพาะจุดที่เกี่ยวข้องได้ น้ำมากและน้ำน้อยเป็นคนละกลุ่มเหตุการณ์

บทพยากรณ์ในหน้าภาพรวมและหน้า `/rain`, `/air`, `/heat` มีแผนที่จุดพยากรณ์ตามช่วงเวลาที่เลือก พร้อมรายชื่อพื้นที่ กรองระดับสี เลือกจุด และเปิดรายละเอียดของจุดนั้น ส่วนข้อมูลถนน น้ำ และฝุ่นตรวจวัดมีแผนที่เพิ่มเติมในหัวข้อที่กางดูได้ ใช้ข้อมูลที่หน้านั้นโหลดอยู่แล้ว ไม่เพิ่มคำขอข้อมูลตรวจวัดชุดใหม่

## ความหมายของแผนที่

- สีแสดงระดับติดตามของ **จุดข้อมูล** ไม่ใช่การประกาศว่าทั้งเขตหรือทั้งจังหวัดมีความเสี่ยงระดับเดียวกัน
- เส้นขอบอ้างอิงใช้ขอบเขตที่ระบบมีอยู่จริง รวมขอบเขตลุ่มน้ำที่ตัดแล้วในพื้นที่ขยาย ไม่มีการสร้าง polygon ผลกระทบจากจุดสถานีเพียงจุดเดียว
- กลุ่มรายพื้นที่ใช้ชื่อเขต/อำเภอของสถานที่จริง หรือจังหวัดของจุดแบบจำลองเมื่อไม่มีรายละเอียดระดับเขต จำนวนคือรายการจุดข้อมูล ไม่ใช่พื้นที่ได้รับผลกระทบ
- เริ่มที่จุดควรติดตาม ผู้ใช้เปิดจุดทั้งหมดหรือเลือกสีเทาเพื่ออ่านจุดที่ยังประเมินไม่ได้ได้ ไม่แสดงค่าที่ขาดเป็นศูนย์หรือสถานการณ์ปกติ
- รายละเอียดแยกตรวจวัด, Nowcast และพยากรณ์ พร้อมหน่วย ช่วงข้อมูล เวลา และต้นทางของจุดนั้น

## เกณฑ์สี

สีแดง = สูงมาก, ส้ม = สูง, เหลืองเข้ม = เฝ้าระวัง, น้ำเงิน = ไม่เข้าเกณฑ์ติดตาม, เทา = ยังประเมินไม่ได้ ความหมายเป็นระดับติดตามตามเกณฑ์ของเรื่องนั้น ไม่ใช่ค่าความน่าจะเป็นร่วมกันระหว่างทุกเรื่อง

| เรื่อง | เกณฑ์และข้อจำกัด |
| --- | --- |
| น้ำบนถนน | ใช้สถานะจาก กทม. ที่ยังใหม่: น้ำท่วม/ท่วมเล็กน้อย/ปกติ ข้อมูลเก่าหรือใช้ไม่ได้เป็นสีเทา |
| คลอง/แม่น้ำ | ใช้ความจุหรือตลิ่งที่ datum สอดคล้องกันตามเกณฑ์เดิม แสดง “น้ำมาก” และ “น้ำน้อย” ในรายละเอียด ไม่ใช้ค่าน้ำต่ำเท่ากับความเสี่ยงน้ำท่วม |
| ฝุ่นตรวจวัด | ใช้ระดับสีที่หน่วยงานส่งมา ไม่เอาค่าที่ไม่ทราบช่วงเฉลี่ยเทียบเกณฑ์รายวัน ค่าปัจจุบันที่ไม่มีระดับต้นทางยังอ่านได้ แต่ประเมินระดับไม่ได้ |
| ฝนใกล้พื้นที่ | จุดหมายถึงตำแหน่งที่ขอวิเคราะห์รอบ 8 กม. ใช้ผล TMD ที่ผ่านเกณฑ์ความใหม่ เมื่อพบสัญญาณจัดเป็น “เฝ้าระวัง” ไม่สรุปความรุนแรงจากคำตอบพบ/ไม่พบ และไม่ใช่ polygon กลุ่มฝนหรือขอบเขตฝนที่ตกจริง |
| ความร้อนปัจจุบัน | ใช้ดัชนีความร้อนของชั่วโมง/ช่วงปัจจุบันจากแบบจำลอง ไม่ใช้ยอดสูงสุดรายวันแทนค่าตอนนี้ |
| ฝนพยากรณ์ | เมื่อเลือกยอดสะสมทั้งวัน ใช้ >10, >35, >90 มม. สำหรับระดับติดตาม รายชั่วโมง/หลายชั่วโมงใช้โอกาสฝน ≥60/≥80% แยกจากปริมาณ ไม่ใช้เกณฑ์ทั้งวันกับยอดรายชั่วโมง |
| ฝุ่นพยากรณ์ | ใช้ค่าเฉลี่ยรายวัน >25, >37.5, >75 µg/m³ ตามเกณฑ์เดิม |
| ความร้อนพยากรณ์ | ใช้ดัชนีความร้อน ≥33, ≥42, ≥52°C แม้ผู้ใช้เลือกอ่านอุณหภูมิอากาศในแผนที่หลัก |

ค่าถนน น้ำ และฝุ่นหมดอายุตามเกณฑ์เดียวกับสรุปเรื่องสำคัญ สีเทาจึงยังคงเป็นสีเทาเมื่อข้อมูลเก่า แม้ต้นทางเคยส่งระดับรุนแรงไว้ การเลือกวันอนาคตเปลี่ยนเฉพาะแผนที่พยากรณ์ ไม่เปลี่ยนสรุปเหตุการณ์ปัจจุบัน

## การใช้งานและประสิทธิภาพ

แผนที่เริ่มทำงานเมื่ออยู่ใกล้หน้าจอ มีปุ่มซูม จุดเลือกด้วยคีย์บอร์ดได้ และมีรายการรายพื้นที่ที่อ่านได้แม้แผนที่หรือภาพพื้นหลังโหลดไม่สำเร็จ การเลือกจุดจากรายการจะเลื่อนแผนที่ไปยังจุดนั้น การย้ายกล้องไม่ทำ animation ต่อเนื่อง สีมีชื่อระดับและสถานะกำกับ ใช้ได้ทั้งโหมดสว่าง/มืดและหน้าจอมือถือ
