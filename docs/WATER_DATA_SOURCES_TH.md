# ข้อมูลระดับน้ำในเว็บ

หน้า overview ใช้ปริมาณฝนสะสมรายวันเป็นข้อมูลฝนหลัก รวมถึงรายการพื้นที่ที่ควรติดตาม ส่วนโอกาสฝนยังเป็นข้อมูลเสริมในเครื่องมือรายละเอียด

## แหล่งระดับน้ำ

- [ThaiWater / คลังข้อมูลน้ำแห่งชาติ](https://www.thaiwater.net/water): ใช้ข้อมูลสาธารณะ `waterlevel_data` จาก `https://api-v3.thaiwater.net/api/v1/thaiwater30/public/waterlevel_load` โดยแสดงหน่วยงานที่ตรวจวัดจริงในแต่ละสถานี
- [มาตรฐานการวัดระดับน้ำของ สสน.](https://standard.thaiwater.net/): ระดับน้ำทะเลปานกลางใช้หน่วยเมตร รทก. ไม่ใช่ความลึกน้ำท่วม
- [แผนที่คลองสำนักการระบายน้ำ กทม.](https://weather.bangkok.go.th/KlongMap): ลิงก์ให้ผู้ใช้เปิดตรวจข้อมูลคลองของ กทม. โดยตรง ส่วนค่าที่เว็บนี้แสดงมาจาก ThaiWater

ขอบเขตคือกรุงเทพฯ นนทบุรี ปทุมธานี สมุทรปราการ สมุทรสาคร และนครปฐม ตามรหัสจังหวัดที่ต้นทางระบุ ความครอบคลุมขึ้นอยู่กับสถานีที่ต้นทางส่งมา ไม่อ้างว่ามีทุกคลองหรือทุกย่าน

## การใช้ข้อมูล

- ใช้ค่าตรวจวัดรายสถานีและพิกัดของสถานีจริง ไม่ทำ IDW ไม่เฉลี่ยระดับน้ำทั้งจังหวัด และไม่ผูกกับวันที่ในพยากรณ์ 7 วัน
- แปลงเวลาไม่มี timezone ของต้นทางเป็นเวลาไทย `+07:00` ข้อมูลภายใน 60 นาทีเป็นข้อมูลล่าสุด; เกิน 60 นาทีแสดงสถานะข้อมูลเก่า; เกิน 24 ชั่วโมงไม่แสดงตัวเลข
- ไม่ใช้เวลาผิดรูปแบบ วันที่ไม่มีจริง หรือเวลาที่อยู่ในอนาคตเกิน 5 นาทีเป็นค่าล่าสุด ค่าที่ขาดไม่แทนด้วยศูนย์ ระดับน้ำติดลบและศูนย์จริงยังคงอยู่
- ใช้ `waterlevel_msl` ก่อน ถ้ามีเฉพาะ `waterlevel_m` จะแสดงเป็นระดับอ้างอิงสถานี และไม่เทียบกับตลิ่ง รทก.
- เทียบ `min_bank` กับระดับน้ำเฉพาะข้อมูลล่าสุดที่อ้างอิง รทก. เหมือนกัน เป็นการเปรียบเทียบที่สถานี ไม่ใช่ประกาศเตือนภัยหรือข้อสรุปว่าน้ำท่วมทั้งพื้นที่
- แสดงตัวเลขอย่างน้อย 2 และไม่เกิน 3 ตำแหน่งทศนิยม เพื่อไม่ปัดความต่างระดับเซนติเมตรให้กลายเป็นศูนย์
- แสดง `storage_percent` เป็นเปอร์เซ็นต์ความจุลำน้ำจากต้นทาง ไม่ใช่โอกาสน้ำท่วม และไม่คำนวณขึ้นเอง ใช้ [เกณฑ์ ThaiWater](https://tiwrm.hii.or.th/thaiwater_l5/public/telemetering/wl/warning): ≤10 น้ำน้อยวิกฤติ; >10–30 น้ำน้อย; >30–70 น้ำปกติ; >70–100 น้ำมาก; >100 น้ำล้นตลิ่ง เฉพาะค่าที่สดและใช้ได้
- ถ้าไม่มีเปอร์เซ็นต์ความจุ จะไม่สมมติค่าหรือจัดสถานะปกติจากการอยู่ต่ำกว่าตลิ่ง ใช้สัญญาณถึงตลิ่งได้เมื่อระดับน้ำล่าสุดเทียบกับตลิ่งใน datum เดียวกันถึงหรือเกินค่าที่ต้นทางระบุ
- อินโฟกราฟิกแนวดิ่งใช้ระดับน้ำ ตลิ่ง และ `ground_level` จากต้นทางใน รทก. เมื่อค่าท้องน้ำใช้ได้ หากไม่มีค่าท้องน้ำจะแสดงกราฟเปรียบเทียบแนวนอนเดิม ภาพเคลื่อนไหวเป็นการเผยค่าหลังเลือกสถานี ไม่ใช่แนวโน้มหรือระดับที่กำลังเพิ่มขึ้นจริง
- ภาพแนวดิ่งใช้ได้เมื่อระดับท้องน้ำต่ำกว่าตลิ่งและระดับน้ำไม่ต่ำกว่าท้องน้ำ ถ้าเงื่อนไขนี้ไม่ครบ ใช้กราฟแนวนอนที่เทียบ datum ตรงกัน ข้อมูลเก่า หมดอายุ หรือเวลาอนาคตที่ใช้ไม่ได้ไม่สร้างกราฟหรือสถานะความจุปัจจุบัน
- การเคลื่อนไหวเผยพื้นที่น้ำ 650 มิลลิวินาทีและลากเส้นผิวน้ำ 900 มิลลิวินาทีเพียงครั้งเดียวเมื่อเปลี่ยนสถานีหรือเวลาค่าตรวจวัด ไม่เล่นวน ปุ่มพักภาพและ reduced motion แสดงรูปทรงปลายทางแบบนิ่ง ไม่ใช้ไลบรารีเคลื่อนไหวเพิ่มเติม
- โหลดใหม่ทุก 5 นาที; HTTP cache 60 วินาทีและ CDN cache 300 วินาที; แหล่งข้อมูลล้มเหลวส่งสถานะ unavailable และให้ผู้ใช้ลองโหลดใหม่
- เมื่อเลือกย่านจะเรียงสถานีที่ข้อมูลพร้อมใกล้จุดอ้างอิงสาธารณะก่อน ระยะเป็นการประมาณเส้นตรง ไม่ใช่ระดับน้ำ ณ ตำแหน่งผู้ใช้

## การตรวจสอบ

Unit tests ตรวจเวลาไทย ความสดข้อมูล ค่าติดลบ ศูนย์จริง ค่าขาด เวลาผิด/อนาคต การใช้ datum ตรงกัน การกรองจังหวัด การเลือกสถานีใกล้ย่าน และกรณีต้นทางล้มเหลว รายการฝนสะสมตรวจว่าไม่แสดงสัญญาณโอกาสฝนล้วนบน overview

ตรวจรอบนี้ผ่าน 135 unit tests และ 32 rendered tests, lint, Next.js build และ Cloudflare build พรีวิวเบราว์เซอร์ยืนยันตัวกรองจังหวัด การเลือกสถานีบนมือถือ การแสดงสถานะเมื่อต้นทางล้มเหลว และกรณีข้อมูลเก่าที่ไม่แสดงกราฟเทียบตลิ่ง ภาพหน้าจอรอบแก้ไขอยู่ใน `output/playwright/water-desktop-final.png`, `water-mobile-final.png` และ `water-mobile-stale-final.png`

รอบปรับสถานะความเสี่ยงและภาพเคลื่อนไหวล่าสุดผ่าน 137 unit tests และ 32 rendered tests (รวม 169), lint, Next.js build และ Cloudflare build ตรวจสถานีข้อมูลสดที่เข้าเกณฑ์ติดตาม 17 แห่ง ณ เวลาทดสอบ; สถานี ID 5 (คลองมหาสวัสดิ) ที่มีข้อมูลเก่ายังประเมินไม่ได้และไม่แสดงเปอร์เซ็นต์ความจุหรือกราฟ; การโหลดน้ำที่ถูกยกเลิกมีสถานะประเมินไม่ได้และปุ่มลองใหม่; ปุ่มพักภาพปิด animation และ reduced motion แสดงภาพนิ่ง รอบนี้ตรวจภาพเคลื่อนไหวทำงานที่ 100 มิลลิวินาทีและเผยพื้นที่น้ำจบภายใน 850 มิลลิวินาที ภาพล่าสุดอยู่ใน `output/playwright/risk-desktop-water-final.png`, `risk-mobile-water-final.png` และ `risk-mobile-dark-final.png` ไม่อ้างว่าทดสอบ screen reader, การขยายข้อความ 200%, ทุกเบราว์เซอร์ หรือ detector
