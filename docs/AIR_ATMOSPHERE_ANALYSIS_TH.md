# บทวิเคราะห์ฝุ่น ปัจจัยอากาศ และลมหนาว

เพิ่มในเรื่องฝุ่นของหน้าภาพรวม หลังกราฟพยากรณ์ PM2.5 โดยยังคงลำดับฝนและน้ำ → ฝุ่น → ความร้อน ข้อมูลปัจจัยอากาศช่วยอ่านแนวโน้ม ไม่แก้ค่าพยากรณ์จากโมเดลฝุ่นเดิม และไม่ระบุว่าแหล่งกำเนิดใดเป็นสาเหตุหรือมีส่วนกี่เปอร์เซ็นต์

## แหล่งข้อมูลและเวลา

- NOAA GFS ผ่าน [Open-Meteo GFS API](https://open-meteo.com/en/docs/gfs-api): ลมที่ระดับ 10 เมตร อุณหภูมิ/ความชื้นที่ 2 เมตร ฝน ความกดอากาศระดับน้ำทะเล และ boundary-layer height
- ขอข้อมูลรายชั่วโมงในเขตเวลา Asia/Bangkok หน่วย km/h, °C, %, mm, hPa และ m แล้วตรวจหน่วยก่อนใช้ ค่าที่ผิดหน่วย ผิดช่วง หรือขาดหายยังคงเป็น null
- แสดงวันนี้และอีก 7 วัน พร้อม 2 วันก่อนหน้าสำหรับเปรียบเทียบ ช่วงย้อนหลังเป็นข้อมูลจากแบบจำลอง ไม่ใช่ค่าตรวจวัดสถานี
- ขอเพิ่มวันปลายทางเพื่อให้ได้ค่า 00:00 ของวันถัดไปสำหรับปิดยอดฝนวันสุดท้าย ฝนรายชั่วโมงเป็นยอดสะสมของหนึ่งชั่วโมงก่อนเวลาที่ระบุ ยอดวันปฏิทินจึงรวม 01:00 ของวันนั้นจนถึง 00:00 ของวันถัดไป
- ค่าเฉลี่ยต้องมีอย่างน้อย 18 จาก 24 ชั่วโมง ฝนสะสมวันต้องครบ 24 ชั่วโมง อุณหภูมิต่ำสุดช่วง 00:00–08:00 ต้องครบ 9 ชั่วโมง แสดงตัวหารจริงเมื่อสรุปชั่วโมงลมอ่อน
- เวลาที่แสดงว่า “โหลดข้อมูล” คือเวลาที่รับข้อมูลจาก API ไม่ใช่เวลารันโมเดล แสดงพิกัดกริดที่ต้นทางคืนมาแยกจากจุดอ้างอิงของผู้ใช้

## การอ่านลมกับฝุ่น

ทิศเฉลี่ยใช้ค่าเฉลี่ยเวกเตอร์แบบวงกลม ถ่วงด้วยความเร็วลม เพื่อไม่ให้ลม 359° และ 1° กลายเป็นลมใต้ หากลมสงบหรือทิศหักล้างกันมาก จะไม่แสดงทิศเฉลี่ยที่ไม่มีความหมาย ลูกศรเข็มทิศชี้ทางที่ลมพัดไป ส่วนคำอธิบายระบุทิศที่ลมพัดมา

แอปนับชั่วโมงที่มีลม ≤5 กม./ชม. และชั้นอากาศผสม ≤300 เมตรพร้อมกัน โดยต้องมีข้อมูลทั้งสองตัวในเวลาเดียวกันอย่างน้อย 18 ชั่วโมง นี่เป็นเกณฑ์อ่านปัจจัยร่วมของแอป ไม่ใช่ค่า Ventilation Rate ของกรมอุตุฯ ความสูงชั้นอากาศไม่ได้ยืนยันการผกผันอุณหภูมิ ลมอาจกระจายฝุ่นหรือพาอากาศจากพื้นที่อื่นเข้ามา จึงไม่ใช้ทิศลมเพียงอย่างเดียวระบุแหล่งมลพิษ

ฝนอาจช่วยชะล้างอนุภาค แต่ปริมาณน้อยไม่รับประกันว่าฝุ่นจะลด ความชื้นเกี่ยวข้องกับการดูดน้ำและการเติบโตของอนุภาค ต้องอ่านร่วมกับลมและชั้นอากาศ [งานวิจัยการเติบโตของอนุภาคเมื่อความชื้นเปลี่ยน](https://acp.copernicus.org/articles/22/7681/2022/) สนับสนุนกลไกทั่วไป แต่ไม่ได้เป็นสมการทำนาย PM2.5 สำหรับกรุงเทพฯ

เปรียบเทียบค่าฝุ่นเฉลี่ยรายวันของสองวันติดกันเท่านั้น ไม่ใช้ค่าตรวจวัดล่าสุดแทนค่าพยากรณ์ของวันก่อนเมื่อพยากรณ์นั้นขาดหาย

## เกณฑ์ทดลองของแนวโน้มลมหนาว

ต้องพบพร้อมกันทั้งสามเงื่อนไขในวันเดียวกัน:

1. ลมมาจากช่วงทิศ 315°–90° และเร็ว ≥5 กม./ชม. ในอย่างน้อย 50% ของชั่วโมงที่มีข้อมูลลม
2. อุณหภูมิต่ำสุดช่วง 00:00–08:00 ลด ≥2°C จากวันก่อนหน้า
3. ความกดอากาศระดับน้ำทะเลเฉลี่ยรายวันเพิ่ม ≥1.5 hPa จากวันก่อนหน้า

หากมีลมฝ่ายเหนือแต่หลักฐานเย็นลงยังไม่ครบ ให้แสดงสถานะนั้น หากหลักฐานขาด ให้แสดงข้อมูลยังไม่พอ และนับจำนวนวันที่ประเมินได้แยกจากจำนวนวันทั้งหมด เกณฑ์นี้เป็นการอนุมานที่กริดเดียว ไม่ยืนยันมวลอากาศเย็นจากจีน การเริ่มฤดูหนาว หรือคำเตือนของหน่วยงาน

กรมอุตุนิยมวิทยาอธิบายว่าความกดอากาศสูง สภาพอากาศผกผัน และลมสงบเกี่ยวข้องกับการสะสมฝุ่น รวมทั้งต้องพิจารณาการกระจายตัวของอากาศ ดู [ระบบฝุ่นและการระบายอากาศ](https://ozone.tmd.go.th/PM2.5/dashboard/) และตรวจ [พยากรณ์อากาศ 7 วัน](https://www.tmd.go.th/forecast/sevenday) ประกอบการอ่านกริดท้องถิ่น

## ประสิทธิภาพและการนำเสนอ

API `/api/air-atmosphere` รับจังหวัดและพิกัดในกรุงเทพฯ–ปริมณฑล ใช้จุดอ้างอิง 0.02° เพื่อแบ่งปันคำขอของกริดใกล้กัน ไม่อ้างความละเอียดระดับถนน ไม่เขียนพิกัดผู้ใช้ลงฐานข้อมูล ใช้แคชหน่วยความจำสูงสุด 96 จุด รวมคำขอที่กำลังรอ และมี timeout 12 วินาที แคชไม่เกิน 15 นาทีและสิ้นสุดก่อนวันใหม่ของกรุงเทพฯ แหล่งข้อมูลล้มเหลวแสดง unavailable และไม่เก็บแคชข้อมูลที่ว่าง

กราฟเก็บช่องว่างข้อมูลและแยกหน่วย ไม่รวมลมกับ PM2.5 บนแกนเดียวกัน อุณหภูมิและความกดอากาศใช้แกนที่ขยายช่วงพร้อมคำอธิบาย มีตารางค่าจริง ปุ่มเลือกปัจจัยและความละเอียด รวมถึงเข็มทิศที่เผยรูปทรงจริงหนึ่งครั้งและหยุดแอนิเมชันเมื่อผู้ใช้ลดการเคลื่อนไหว

การทดสอบครอบคลุมหน่วย/ศูนย์/ช่องว่าง ทิศลมแบบวงกลม ลมสงบและทิศหักล้าง การรวมฝนก่อนเวลาระบุ การเปรียบเทียบวันติดกัน เกณฑ์ลมหนาว พิกัดไม่ถูกต้อง API ล้มเหลว และแคชที่สิ้นสุดตอนเที่ยงคืน รวมทั้งการจัดบทวิเคราะห์ไว้ในเรื่องฝุ่นเท่านั้น
