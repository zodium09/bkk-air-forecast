# สรุปเรื่องสำคัญและการแจ้งเตือนบนหน้าแรก

ส่วน `important-events` อยู่หลังเมนูและก่อนภาพแนะนำบนหน้าแรก ใช้รายการที่เข้าเกณฑ์จากข้อมูลจริง เรียงตามระดับและเรื่องที่ต้องตรวจต่อ กดแต่ละรายการเพื่อไปยังข้อมูลเรื่องนั้น มีเวลาของค่าล่าสุดในกลุ่ม แหล่งข้อมูล และประเภทตรวจวัด/Nowcast/พยากรณ์กำกับ

## พื้นที่และเวลา

- ไม่เลือกพื้นที่: รวมจุดที่มีข้อมูลในจังหวัดหรือกรุงเทพฯ–ปริมณฑลที่เลือก
- เลือกพื้นที่: ใช้ตำแหน่งจริงของจุดวัดหรือจุดแบบจำลองในรัศมี 8 กม. จากจุดอ้างอิง ไม่ใช้ค่าเฉลี่ยเขตหรือ IDW สร้างเหตุการณ์
- ฝนระยะสั้นต้องเลือกจุดก่อนจึงอ่านผลวิเคราะห์ตำแหน่งได้
- สรุปบนสุดยึดเวลาปัจจุบันของกรุงเทพฯ แยกจากวันพยากรณ์ที่เลือกด้านล่าง
- จำนวนหมายถึงรายการจุดข้อมูล ไม่ใช่จำนวนเขต ขอบเขตผลกระทบ หรือจำนวนเซลล์แบบจำลองที่ไม่ซ้ำกัน

## เกณฑ์และแหล่งข้อมูล

1. ถนน: สถานะน้ำท่วม/น้ำท่วมเล็กน้อยที่สำนักการระบายน้ำ กทม. ส่งมา ใช้ค่าภายใน 30 นาที ชุดข้อมูลครอบคลุมกรุงเทพฯ [ต้นทาง](https://weather.bangkok.go.th/flood/)
2. น้ำ: ใช้ `waterRisk` เดิมจากเกณฑ์ความจุ ThaiWater หรือระดับตลิ่งใน datum เดียวกัน ใช้ค่าภายใน 60 นาที แยกน้ำมาก/ถึงตลิ่งออกจากน้ำน้อย/น้อยวิกฤติ สถานีที่มีระดับน้ำแต่ไม่มีเกณฑ์ยังประเมินไม่ได้ [ต้นทาง](https://www.thaiwater.net/water)
3. ฝุ่น: ใช้ระดับส้ม/แดงที่ต้นทางส่งพร้อมค่าภายใน 90 นาที ไม่อนุมานช่วงเฉลี่ยและไม่ใช้เกณฑ์เฉลี่ยรายวันเทียบกับค่าที่ไม่ระบุช่วงเฉลี่ย รายการสถานีต่างแหล่งที่ไม่ทราบช่วงเฉลี่ยไม่ได้รวมเป็นสถานีเดียว [AirBKK](https://official.airbkk.com/airbkk/Api), [Air4Thai](https://air4thai.pcd.go.th/services/getNewAQI_JSON.php)
4. ฝน: ใช้ผลวิเคราะห์ `found` และข้อความต้นทางจาก TMD RadarGIS ตาม [สัญญาข้อมูลเรดาร์](RAIN_RADAR_NEARBY_TH.md) ไม่คำนวณเวลาเดินทางของเมฆเอง
5. ความร้อน: ใช้ค่าพยากรณ์ดัชนีความร้อนที่จุดแบบจำลองในชั่วโมงปัจจุบันก่อน หากไม่มีจึงใช้ช่วงปัจจุบันที่ต้นทางมีครบ แสดงช่วงเวลาชัดเจน ใช้การติดตามตั้งแต่ 42°C และระดับสูงขึ้นตั้งแต่ 52°C ตามเกณฑ์ในแอปเดิม ไม่ใช้ยอดสูงสุดทั้งวันหรือวันพรุ่งนี้แทนข้อมูลตอนนี้ ชุดที่ดึงเกิน 3 ชั่วโมงไม่เข้าสรุป

สรุปแสดงความครบของข้อมูลทั้งห้าเรื่อง ข้อมูลเก่า ขาด ไม่มีเกณฑ์ หรือไม่มีความครอบคลุมไม่ถูกนับเป็นสถานการณ์ปกติ ไม่สรุปว่าทุกพื้นที่ปลอดภัยเมื่อไม่มีรายการเข้าเกณฑ์

## การแจ้งเตือน

ผู้ใช้เปิดด้วยปุ่มบนแถบสรุป แจ้งภายในหน้านี้และอัปเดตทุก 5 นาทีขณะเปิดแอป เมื่อเปิดครั้งแรกจะแสดงรายการที่ยังเข้าเกณฑ์อยู่ จากนั้นแจ้งเมื่อมีประเภทเรื่องใหม่ จำนวนในระดับที่หนักที่สุดเพิ่ม หรือระดับเพิ่ม การเปลี่ยนเวลาอย่างเดียวไม่สร้างแจ้งเตือนใหม่

รับทราบแล้วข้อความเดิมไม่เด้งซ้ำ สถานการณ์คลี่คลายจะล้างรายการค้าง หากกลับเข้าเกณฑ์ภายหลังแจ้งได้อีกครั้ง เมื่อเปลี่ยนพื้นที่จะใช้รายการของพื้นที่ใหม่และเอาข้อความพื้นที่เก่าออก ปิดปุ่มแล้วล้างแจ้งเตือนที่ค้างอยู่ ไม่มีการส่งอีเมล เสียง หรือการแจ้งเตือนระบบปฏิบัติการ และไม่เก็บตำแหน่งหรือประวัติการรับทราบข้ามหน้า

หน้าแรกส่งข้อมูลชุดเดียวกันให้สรุปและส่วนรายละเอียดถนน น้ำ ฝุ่น และเรดาร์ จึงไม่อ่าน API ซ้ำสำหรับการสรุป ปุ่มอัปเดตในส่วนเหล่านี้อัปเดตข้อมูลร่วมกัน หน้าเฉพาะเรื่องยังอ่านข้อมูลได้เองตามเดิม ไม่ใช้ข้อมูลจำลองจาก `/surveillance` มาสรุปสถานการณ์จริง

การทดสอบครอบคลุมอายุข้อมูล พิกัด จังหวัด เกณฑ์จากต้นทาง การแยกศูนย์/ขาด ความละเอียดของช่วงความร้อน ผลฝนที่หมดอายุ และวงจรเปิด/รับทราบ/เพิ่มระดับ/เปลี่ยนพื้นที่/คลี่คลาย/กลับเข้าเกณฑ์ของการแจ้งเตือน
